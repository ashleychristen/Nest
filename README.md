# NEST website

Responsive static HTML/CSS recreation based on the Canva screenshots you supplied.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **public** repository named `club` (or your chosen project name).
2. Upload the contents of this folder to the repository root: `index.html`, `style.css`, and `images/`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a minute or two for deployment.

For a repository named `club`, the URL is `https://YOUR-USERNAME.github.io/club/`.

## Important notes
- The photos in `images/` are crops from the screenshots you provided. Replace them with original Canva image files for best quality if available.
- Please review all hospital/program wording, names, and claims before publishing. The page reproduces the information visible in the screenshots; it does not verify it.
- Google Fonts loads when internet access is available; fallback fonts are included.
